Небольшое свободное Android-приложение для установки MP4-видео как живых обоев. Главная задача проекта — не только проигрывать ролик, но и корректно сообщать Android его палитру, чтобы поддерживающая это система могла использовать цвета обоев для системной темы, в том числе на Android 16 / LineageOS.

## Почему это отдельное приложение

Видеопроигрыватель живых обоев должен реализовать два независимых механизма: выводить видео на `Surface` и предоставлять системе сведения о цветах обоев. Одного воспроизведения недостаточно: если `WallpaperService.Engine` не отдаёт палитру, система может оставить текущие или стандартные цвета темы.

В проекте для этого используется публичный API Android:

1. После выбора видео приложение с помощью `MediaMetadataRetriever` извлекает пять небольших кадров, равномерно распределённых по ролику.
2. Кадры собираются в миниатюрную полосу и передаются платформе через `WallpaperColors.fromBitmap()`. Приложение не декодирует и не хранит весь MP4 в памяти.
3. Первичный, вторичный и третичный цвета сохраняются вместе с выбранным URI. Сервис обоев возвращает их в `WallpaperService.Engine.onComputeColors()`.
4. После выбора или удаления ролика сервис вызывает `notifyColorsChanged()`, чтобы система повторно запросила палитру. На Android 12+ сохраняются также цветовые подсказки `WallpaperColors`.

Это тот же важный системный контракт, который использует GIF Live Wallpaper из референса, но источник кадров здесь — MP4. Итоговое применение динамических цветов остаётся за прошивкой: Android/SystemUI должен поддерживать палитру живых обоев; приложение не может принудительно менять тему поверх системной политики.

## Возможности

- Выбор MP4 через системное окно документов Android — без широкого доступа ко всему хранилищу и без запроса разрешения на чтение всех видео.
- Видео зациклено, без звука; воспроизводится платформенным `MediaPlayer` непосредственно на поверхности живых обоев.
- Доступ к выбранному файлу сохраняется через SAF (`ACTION_OPEN_DOCUMENT` и persistable URI permission), файл не копируется в каталог приложения.
- Цвета рассчитываются по пяти кадрам размером до 64 × 64 пикселя; кэшируется только палитра, не видеопоток.
- Предпросмотр и установка выполняются штатным экраном Android. Там можно выбрать главный экран, экран блокировки или оба варианта — если прошивка это поддерживает.
- Интерфейс на русском и английском языках. Сетевого доступа у приложения нет.

## Установка и использование

1. Установите APK из [предварительного выпуска 0.0.1](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/tag/v0.0.1). Это ранняя версия: перед постоянным использованием проверьте её на своей модели телефона и прошивке.
2. Откройте **MP4 обои** и нажмите **Выбрать MP4**.
3. Выберите файл в системном файловом окне и дождитесь появления трёх вычисленных цветов.
4. Нажмите **Предпросмотр и установка**, просмотрите ролик и подтвердите установку в системном диалоге.
5. Если ROM не обновил системную тему сразу, проверьте палитру после применения обоев или перезапустите системный экран выбора обоев. Сама политика применения Monet/динамических цветов зависит от прошивки.

Для остановки и очистки выбранного видео нажмите **Убрать выбранное видео** в приложении.

### Совместимость

- Android 8.1 (API 27) и новее. API 27 — минимальная версия, в которой доступен `WallpaperColors` для палитры живых обоев.
- Требуется системная поддержка живых обоев.
- Поддерживаются MP4-файлы, кодеки которых воспроизводятся Android `MediaPlayer` на конкретном устройстве. Контейнер MP4 сам по себе не гарантирует поддержку любого видеокодека.
- Для задачи палитры на Android 16 важны реализации `WallpaperColors` и живых обоев в конкретной сборке LineageOS/SystemUI. Проект реализует публичный API; подтверждение на разных устройствах ещё предстоит.

## Сборка из исходников

Требуются JDK 17 и Android SDK Platform 35.

```bash
./gradlew assembleRelease
```

Неподписанный APK будет создан по пути `app/build/outputs/apk/release/app-release-unsigned.apk`. Его следует подписать собственным ключом для ручной установки. Для F-Droid приложение собирается из исходников и подписывается инфраструктурой F-Droid.

- `app/build.gradle` содержит `versionName 0.0.1` и `versionCode 1`.
- `metadata/io.github.alexeynaverno.wallpapermp4.yml` — подготовленная запись для fdroiddata.
- `.github/workflows/android.yml` собирает APK и прикладывает его к GitHub Release после создания тега `v*`.

## Разрешения и приватность

Приложение объявляет только `SET_WALLPAPER`. Выбор файла и доступ к нему выполняются через системный SAF-пикер с постоянным разрешением только на выбранный URI. Приложение не объявляет разрешений `INTERNET`, `READ_MEDIA_VIDEO` или `READ_EXTERNAL_STORAGE`, не отправляет ролики и палитры в сеть.

## Референсы и системный API

- [cyunrei/Video-Live-Wallpaper](https://github.com/cyunrei/Video-Live-Wallpaper) — пример минималистичных MP4-обоев.
- [GIF Live Wallpaper в F-Droid](https://f-droid.org/packages/net.redwarp.gifwallpaper/) и [исходный код](https://github.com/redwarp/gif-wallpaper) — референс для передачи цветов живых обоев.
- [WallpaperService.Engine](https://developer.android.com/reference/android/service/wallpaper/WallpaperService.Engine#onComputeColors()) — API вычисляемых цветов сервиса обоев.
- [WallpaperColors](https://developer.android.com/reference/android/app/WallpaperColors#fromBitmap(android.graphics.Bitmap)) — извлечение системной палитры из bitmap.
