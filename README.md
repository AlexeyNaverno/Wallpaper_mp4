Небольшое свободное Android-приложение для MP4-видеообоев. Видео по умолчанию проигрывается вперёд, затем — назад, после чего цикл повторяется. Помимо воспроизведения, приложение сообщает Android палитру ролика, чтобы поддерживающая это система могла использовать её для системной темы, в том числе на Android 16 / LineageOS.

## Циклическое воспроизведение без повтора концов

Обычный `MediaPlayer` не поддерживает надёжную отрицательную скорость для обратного воспроизведения на разных Android-устройствах. Поэтому приложение использует следующий ping-pong алгоритм:

1. Платформенный `MediaPlayer` воспроизводит видео вперёд без звука.
2. После последнего кадра сервис отсоединяет декодер от поверхности и последовательно запрашивает кадры в обратном порядке через `MediaMetadataRetriever`.
3. Обратный проход начинается перед последним кадром и заканчивается после первого: крайние кадры не дублируются на разворотах.
4. Сервис подключает `MediaPlayer` обратно и запускает следующий прямой проход с начала.

Обратные кадры обрабатываются в отдельном потоке и выдаются по одному, с ограничением размера кадра до 1080 пикселей по длинной стороне — целиком видео в память не загружается. Частота обратного прохода ограничена 30 кадрами/с, а на слабых декодерах фактический темп может быть ниже. Если устройство не может извлечь кадры выбранного MP4 через системный `MediaMetadataRetriever`, приложение возвращается к обычному зацикленному воспроизведению.

## Палитра Android / LineageOS

Проблема стандартной палитры возникает, когда живые обои показывают изображение, но не сообщают системе его цвета. Проект использует публичный API Android:

1. После выбора видео приложение извлекает пять небольших кадров, равномерно распределённых по ролику.
2. Кадры собираются в миниатюрную полосу и передаются платформе через `WallpaperColors.fromBitmap()`.
3. Первичный, вторичный и третичный цвета сохраняются вместе с выбранным URI. Сервис возвращает их из `WallpaperService.Engine.onComputeColors()`.
4. После выбора или удаления ролика сервис вызывает `notifyColorsChanged()`, чтобы система повторно запросила палитру. На Android 12+ сохраняются также цветовые подсказки `WallpaperColors`.

Это тот же важный системный контракт, который использует GIF Live Wallpaper из референса, но источник кадров здесь — MP4. Применение динамических цветов остаётся за прошивкой: Android/SystemUI должен поддерживать палитру живых обоев; приложение не может принудительно менять тему поверх системной политики.

## Возможности

- Выбор MP4 через системное окно документов Android — без широкого доступа ко всему хранилищу.
- Беззвучное воспроизведение ping-pong по умолчанию: вперёд → назад без повтора крайних кадров → снова вперёд.
- Прямой проход выводится платформенным `MediaPlayer` на поверхность обоев; обратный проход рисуется из кадров, извлекаемых по одному.
- Доступ к выбранному файлу сохраняется через SAF (`ACTION_OPEN_DOCUMENT` и persistable URI permission); исходный видеофайл не копируется в приложение.
- Палитра рассчитывается по пяти кадрам размером до 64 × 64 пикселя; видео и последовательность обратных кадров не кэшируются целиком.
- Предпросмотр и установка выполняются штатным экраном Android. Там можно выбрать главный экран, экран блокировки или оба варианта — если прошивка это поддерживает.
- Интерфейс на русском и английском языках. Сетевого доступа у приложения нет.

## Установка и использование

1. Для быстрой проверки установите [тестовый APK `app-debug.apk`](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/download/v0.0.2/app-debug.apk) из [предварительного выпуска 0.0.2](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/tag/v0.0.2). Он подписан временным debug-ключом CI; при переходе на сборку с другой подписью может понадобиться удалить старое приложение.
2. Откройте **MP4 обои** и нажмите **Выбрать MP4**.
3. Выберите файл в системном файловом окне и дождитесь вычисления трёх цветов.
4. Нажмите **Предпросмотр и установка**, просмотрите ролик и подтвердите установку в системном диалоге.
5. Если ROM не обновил системную тему сразу, проверьте палитру после применения обоев. Политика Monet/динамических цветов зависит от прошивки.

Для остановки и очистки выбранного видео нажмите **Убрать выбранное видео** в приложении.

### Совместимость

- Android 8.1 (API 27) и новее; требуется системная поддержка живых обоев.
- Поддерживаются MP4-файлы, кодеки которых воспроизводятся Android `MediaPlayer` и доступны `MediaMetadataRetriever` на конкретном устройстве.
- Обратный проход декодирует кадры по времени. На устройствах, где системный декодер не умеет извлечь кадры, включается безопасный fallback к обычному циклу вперёд.
- Поведение динамической палитры на Android 16 зависит от реализации `WallpaperColors` и SystemUI конкретной сборки LineageOS; проверка на разных устройствах ещё требуется.

## Сборка из исходников

Требуются JDK 17 и Android SDK Platform 35.

```bash
./gradlew assembleRelease
```

Неподписанный APK будет создан по пути `app/build/outputs/apk/release/app-release-unsigned.apk`; для ручной установки его нужно подписать собственным ключом. CI дополнительно собирает `app-debug.apk` с debug-подписью для тестирования. Это не постоянный ключ проекта и не подпись F-Droid. Для F-Droid приложение собирается из исходников и подписывается инфраструктурой F-Droid.

- `app/build.gradle` содержит `versionName 0.0.2` и `versionCode 2`.
- `metadata/io.github.alexeynaverno.wallpapermp4.yml` — подготовленная запись для fdroiddata.
- `.github/workflows/android.yml` собирает APK и прикладывает его к GitHub Release `v*`.

## Разрешения и приватность

Приложение объявляет только `SET_WALLPAPER`. Выбор файла и доступ к нему выполняются через системный SAF-пикер с постоянным разрешением только на выбранный URI. Приложение не объявляет разрешений `INTERNET`, `READ_MEDIA_VIDEO` или `READ_EXTERNAL_STORAGE`, не отправляет ролики и палитры в сеть.

## Референсы и системный API

- [cyunrei/Video-Live-Wallpaper](https://github.com/cyunrei/Video-Live-Wallpaper) — пример минималистичных MP4-обоев.
- [GIF Live Wallpaper в F-Droid](https://f-droid.org/packages/net.redwarp.gifwallpaper/) и [исходный код](https://github.com/redwarp/gif-wallpaper) — референс для передачи цветов живых обоев.
- [WallpaperService.Engine](https://developer.android.com/reference/android/service/wallpaper/WallpaperService.Engine#onComputeColors()) — API вычисляемых цветов сервиса обоев.
- [WallpaperColors](https://developer.android.com/reference/android/app/WallpaperColors#fromBitmap(android.graphics.Bitmap)) — извлечение системной палитры из bitmap.
