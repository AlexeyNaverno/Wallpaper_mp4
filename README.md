> **Предварительный выпуск 0.0.3.** Ping-pong-видео теперь заранее подготавливается в отдельный MP4 и сохраняется в библиотеке шаблонов приложения.
>
> [Скачать MP4 Live Wallpaper 0.0.3 — GitHub Releases](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/tag/v0.0.3)

Небольшое свободное Android-приложение для MP4-видеообоев. Пользователь импортирует ролик, приложение отдельно создаёт беззвучный MP4 с проходом вперёд и назад, а затем воспроизводит уже готовый файл штатным `MediaPlayer`. Готовые обои хранятся в библиотеке приложения и доступны для повторного выбора. Для каждой записи Android получает вычисленную палитру через публичный live-wallpaper API.

## Подготовка ping-pong-видео

Обратное воспроизведение «на лету» зависит от декодера и часто выглядит неровно. Поэтому при импорте приложение заранее обрабатывает видео:

1. Выберите MP4 через системное окно документов Android.
2. Приложение перечисляет временные метки кадров исходного видеотрека, получает кадры через `MediaMetadataRetriever` и кодирует их в H.264 MP4.
3. Итоговый файл содержит порядок кадров `0…N−1, N−2…1`. Первый и последний кадры обратного прохода не дублируются.
4. Готовый беззвучный MP4 сохраняется в закрытом каталоге приложения. Его можно выбрать в списке, установить, а затем удалить, чтобы освободить место.
5. Live wallpaper проигрывает только готовый MP4 через `MediaPlayer` с обычным повтором файла — в момент показа обоев кадры больше не декодируются в обратном порядке.

Исходный размер кадра сохраняется; если ширина или высота нечётная, кодек может округлить её вверх на один пиксель. Видеофайл полностью перекодируется, звуковая дорожка не включается. Это требует времени и временного места: готовый ролик примерно вдвое длиннее оригинала и занимает дополнительное пространство. Исходный MP4 не изменяется. При нехватке места, неподдерживаемом декодере или отсутствии совместимого H.264-энкодера создание шаблона завершится сообщением об ошибке, а неполный файл будет удалён.

## Палитра Android / LineageOS

Приложение сохраняет вычисленные цвета для каждого шаблона и сообщает их системе через публичный API Android:

1. Из исходного видео выбираются пять небольших кадров, равномерно распределённых по ролику.
2. Кадры собираются в миниатюрную полосу и передаются платформе через `WallpaperColors.fromBitmap()`.
3. Первичный, вторичный и третичный цвета сохраняются вместе с шаблоном. Сервис возвращает их из `WallpaperService.Engine.onComputeColors()`.
4. При выборе или удалении обоев сервис вызывает `notifyColorsChanged()`, чтобы система повторно запросила палитру. На Android 12+ сохраняются также цветовые подсказки `WallpaperColors`.

Приложение не подменяет системные цвета. Применение динамической палитры зависит от прошивки: Android/SystemUI должны поддерживать цвета живых обоев.

## Возможности

- Импорт MP4 через системный SAF-пикер — без широкого доступа ко всему хранилищу.
- Отдельная обработка видео в готовый бесшумный H.264 MP4 с прямым и обратным проходом.
- Библиотека созданных обоев внутри приложения: выбор, применение и удаление шаблонов.
- Исходное разрешение кадра сохраняется; все шаблоны хранятся приватно в каталоге приложения.
- Палитра рассчитывается по пяти кадрам; каждый шаблон сохраняет собственные цвета Android.
- Предпросмотр и установка выполняются штатным экраном Android. Там можно выбрать главный экран, экран блокировки или оба варианта — если прошивка это поддерживает.
- Интерфейс на русском и английском языках. Сетевого доступа у приложения нет.

## Установка и использование

1. Установите тестовый APK [`app-debug.apk`](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/download/v0.0.3/app-debug.apk) из [предварительного выпуска 0.0.3](https://github.com/AlexeyNaverno/Wallpaper_mp4/releases/tag/v0.0.3). Он подписан временным debug-ключом CI; при переходе на сборку с другой подписью может понадобиться удалить старое приложение.
2. Откройте **MP4 обои** и нажмите **Создать обои из MP4**.
3. Выберите видео и дождитесь окончания обработки. Приложение покажет прогресс; обработку можно отменить.
4. Выберите сохранённый шаблон в списке и нажмите **Предпросмотр и установка**.
5. Чтобы освободить место, удалите ненужные шаблоны из списка.

### Совместимость и ограничения

- Android 8.1 (API 27) и новее; требуется системная поддержка живых обоев.
- Устройство должно декодировать выбранный MP4 через Android `MediaMetadataRetriever` и поддерживать H.264-кодирование через `MediaCodec`.
- Создание шаблона — ресурсоёмкая задача; время зависит от длительности и разрешения исходного видео и скорости устройства.
- Звук не копируется. Видео не уменьшается по разрешению, поэтому исходное 4K/высокое разрешение может потребовать много памяти, диска и времени.
- Реальное качество декодирования/кодирования и поведение палитры нужно проверять на устройстве и конкретной прошивке.

## Сборка из исходников

Требуются JDK 17 и Android SDK Platform 35.

```bash
./gradlew assembleRelease
```

Неподписанный APK будет создан по пути `app/build/outputs/apk/release/app-release-unsigned.apk`; для ручной установки его нужно подписать собственным ключом. CI дополнительно собирает `app-debug.apk` с debug-подписью для тестирования. Это не постоянный ключ проекта и не подпись F-Droid. Для F-Droid приложение собирается из исходников и подписывается инфраструктурой F-Droid.

- `app/build.gradle` содержит `versionName 0.0.3` и `versionCode 3`.
- `metadata/io.github.alexeynaverno.wallpapermp4.yml` — подготовленная запись для fdroiddata.
- `.github/workflows/android.yml` собирает APK и прикладывает его к GitHub Release `v*`.

## Разрешения и приватность

Приложение объявляет только `SET_WALLPAPER`. Исходный файл открывается системным SAF-пикером; доступ к нему нужен на время обработки и затем освобождается. Созданные MP4 и метаданные хранятся в приватном каталоге приложения и удаляются вместе с шаблоном. Видео и палитры не отправляются в сеть.

## Системный API

- [WallpaperService.Engine](https://developer.android.com/reference/android/service/wallpaper/WallpaperService.Engine#onComputeColors()) — API вычисляемых цветов сервиса обоев.
- [WallpaperColors](https://developer.android.com/reference/android/app/WallpaperColors#fromBitmap(android.graphics.Bitmap)) — извлечение системной палитры из bitmap.
- Android `MediaCodec` и `MediaMuxer` — обработка кадров и создание MP4 без сторонней FFmpeg-библиотеки.
