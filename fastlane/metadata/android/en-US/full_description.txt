Create a reusable live-wallpaper template from an MP4. The app prepares a silent video that plays forward and then backward, and saves it in a library so you can select, apply or delete it later.

Template creation decodes the source frames and encodes them into one H.264 MP4 in the order 0…N−1, N−2…1. The reverse pass does not repeat the first or last endpoint. The wallpaper service then plays this prepared file with Android MediaPlayer looping; it does not decode frames in reverse while the wallpaper is visible.

The generated video keeps the source resolution and has no audio. Processing takes time and needs temporary storage; the result is about twice the source duration and requires additional space. The original file is not modified. Generated videos stay in the app's private storage and can be removed from the template library.

The app samples five frames from the source, calculates primary, secondary and tertiary colors with Android WallpaperColors, and returns the palette through the live-wallpaper service. Android decides whether and how to apply those colors to its system theme.

Choose MP4 files using Android's document picker. The app retains read access only while processing and does not upload videos or colors. No network permission is used. Requires Android 8.1 (API 27) or later and a device capable of decoding the selected video and encoding H.264 through Android MediaCodec. Results can vary by device and codec.
